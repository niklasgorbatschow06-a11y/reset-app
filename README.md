# RESET

RESET ist eine Daily-Discipline-App für Fokus, Routinen, Streaks und persönliche Entwicklung.

## Features

- Login und Registrierung
- Daily Tasks
- Eigene Aufgaben
- Streak-System
- Premium-System mit Stripe
- KI-Coach mit OpenAI
- Supabase-Datenbank
- Vercel Deployment

## Tech Stack

- Next.js
- Supabase
- Stripe
- OpenAI API
- Vercel
